# README demo capture script

Capture a 10–15 second GIF at 1280×720 or smaller:

1. Open a clean Explorer folder containing `README.md`, `sample.png`, `sample.json`, and `sample.xyz`.
2. Select `README.md` and press Space.
3. Press Right to show the image.
4. Press Right to show JSON as text.
5. Press Right to show the unsupported-file fallback.
6. Click outside the preview to close it.
7. Repeat once with the application set to English if a separate English demo is desired.

Keep the cursor visible, avoid personal file paths, and trim idle time. Do not capture logs, accounts, notification content, or other private desktop information.
